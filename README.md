# Mohamed Elfert — Portfolio

A responsive, static personal portfolio prepared for GitHub Pages.

## Preview locally
Open `index.html` in a browser. No build step is required.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `mohamedelfert.github.io`) under `mohamedelfert`.
2. Upload the contents of this folder to the repository root.
3. In repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub Pages will publish the site at the repository's Pages URL.

## Before publishing
- Add your real CV at `assets/cv/Mohamed-Elfert-CV.pdf`.
- Add a professional portrait at `assets/images/profile.jpg` if you want one; update the hero markup to use it.
- Replace project image placeholders with screenshots you are authorized to publish.
- Add verified contact details (email, LinkedIn) and confirm all experience/project descriptions.
- Review the `8X CRM` and `8X Business` descriptions for employer confidentiality before publishing.

## Files
- `index.html` — page content
- `styles.css` — responsive styling
- `script.js` — mobile navigation and current year
- `assets/` — CV and image assets
